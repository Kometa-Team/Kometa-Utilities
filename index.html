Notes on Privacy

OAuth Token Pages

Plex, Trakt, MyAnimeList, and SIMKL OAuth pages are fully client-side. Your tokens are exchanged directly between your browser and the respective service’s API. No token data is sent to or stored on this server.

Metadata Services

AniDB, SIMKL, and IMDB services cache metadata on this server to improve performance. No personal data is collected or stored. Only publicly available metadata is cached.

Analytics

This site uses Plausible Analytics, a privacy-friendly, self-hosted analytics service. It collects anonymous, aggregated data only — no cookies, no personal data, no fingerprinting.

Source Code

The source code for this project is available on Github for review or self-hosting. Doing so may require you to create additional applications to take the place of the official Kometa apps.
