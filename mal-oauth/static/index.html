MyAnimeList OAuth

Get your MAL access token for Kometa

Use the shared Kometa MyAnimeList application.
  1. Click the Continue to MyAnimeList button.
  2. Authorize the Kometa application on MyAnimeList when prompted.
To connect using your own MAL application you must create one:
  1. Click here to create a MyAnimeList API application.
  2. Enter an Application Name and fill in the required fields.
  3. Enter for App Redirect URL.
  4. Submit the form and record the Client ID and Client Secret; you only need go through this process once.
Now, to authenticate to MyAnimeList:
  1. Enter your Client ID and Client Secret below. MAL requires the Client Secret when exchanging the code for tokens.
  2. Click the Continue to MyAnimeList button.
