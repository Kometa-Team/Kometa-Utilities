Trakt OAuth

Get your Trakt access token for Kometa

To connect to Trakt.tv you must create a Trakt application:
  1. Click here to create a Trakt API application.
  2. Click the "+" in the upper right.
  3. Enter a Name for the application.
  4. Enter for Redirect uri.
  5. You can leave "Description" and "JavaScript (CORS) origins" blank.
  6. Click the `Create` button.
  7. Record the Client ID and Client Secret; you only need go through this process once.
Now, to authenticate to Trakt.tv:
  1. Enter the Client ID and Client Secret into the fields below.
  2. Click the Continue to Trakt button.
