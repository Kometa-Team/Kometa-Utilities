Get your WeTrakr tokens for Kometa

How it works:
  1. Click "Connect with WeTrakr"
  2. A code will appear — open the WeTrakr link and enter it
  3. Sign in and approve the request
  4. Your access and refresh tokens will be displayed here for copying into Kometa's config.yml
Note: WeTrakr access tokens last 7 days and refresh tokens last 180 days — Kometa refreshes both automatically and rewrites its config each time. If Kometa's config is set to read_only, it can't do that, and you'll need to come back here every 7 days instead. Requesting a new code is limited to 5 per 15 minutes, so give it a moment if you've just tried.
